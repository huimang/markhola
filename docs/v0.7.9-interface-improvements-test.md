# v0.7.9 界面改进测试

## 测试目标

验证默认 English、简体中文切换和持久化完整工作；Tab 标题不能被拖选且既有交互不受
影响；Outline 在两种语言下均可见；无用的 macOS 窗口标签命令已移除；两种 Help
文档都与 `v0.7.9` 一致。

## 自动化测试

1. 运行：

   ```bash
   cargo test
   ```

2. 验证语言模型：
   - 未保存或无效偏好返回 English
   - `en` 和 `zh-CN` 可稳定往返
   - `i18n/en.yaml` 和 `i18n/zh-CN.yaml` 都能解析
   - 两个 YAML 文件的 key 集合一致且值非空
   - 缺少翻译 key 时稳定回退到 English
3. 验证 App shell 仍包含：
   - `outlinePanel`
   - `outlineClose`
   - `window.setOutlinePanelOpen`
   - `toggle-outline` IPC
   - `window.applyAppLanguage`
4. 验证 English 和简体中文文案覆盖：
   - 原生一级菜单及其子项
   - 空工作区、查找/替换、Outline、About
   - Tab 按钮和关闭按钮无障碍标签
   - 常用状态消息与未保存确认提示
5. 验证 `.document-tab` 同时包含 `user-select: none` 和
   `-webkit-user-select: none`。
6. 验证原生 View 菜单保留：
   - English `Outline` / 简体中文 `大纲`
   - `toggleOutlinePanel:`
   - `remember_outline_item`
   - Language 子菜单和语言勾选状态
7. 验证 View 菜单清理逻辑识别：
   - `toggleTabBar:`
   - `toggleTabOverview:`
8. 验证 MarkHola 自己的 `Tab` 菜单仍包含既有文档 Tab 命令。
9. 验证 File 菜单不再包含 `Toggle Mode`，Edit 菜单和 `Command + /` 仍可切换模式。
10. 验证以下文件的 `Current version` 都与 `Cargo.toml` 包版本一致：
   - `assets/help/Documentation.md`
   - `assets/help/Documentation.zh-CN.md`

## 构建验证

运行：

```bash
./scripts/build_app.sh
```

确认 `dist/MarkHola.app` 已更新，并确认运行进程路径来自该 bundle。

## 真实界面验证

### 状态一：首次 English 空工作区

1. 在没有已保存语言偏好的条件下启动刚构建的 `dist/MarkHola.app`，不打开文档。
2. 通过无障碍树和截图确认空状态、About 和所有 MarkHola 菜单为 English。
3. 打开 `View` 菜单，确认：
   - `Language > English` 已勾选
   - `Language > 简体中文` 未勾选
   - 显示 `Outline`，且处于禁用状态
   - 不显示空白菜单行或仅显示 selector 名称
   - 不显示 `Show Tab Bar`
   - 不显示 `Show All Tabs`

### 状态二：切换简体中文

1. 选择 `View > Language > 简体中文`。
2. 不重启应用，立即通过无障碍树和截图确认：
   - MarkHola 创建的原生菜单已切换为简体中文
   - 空工作区、About、查找/替换、Outline 和 Tab 无障碍文案已切换
   - `语言 > 简体中文` 已勾选
   - 当前文档、Tab 顺序和编辑状态没有被重建或清空
3. 退出并重新启动，确认仍使用简体中文。
4. 切换回 English，确认界面立即恢复 English，重启后仍为 English。

### 状态三：打开示例文档

1. 运行：

   ```bash
   scripts/qa_open_app.sh examples/workspace-visual.md
   ```

2. 确认实际进程路径属于 `dist/MarkHola.app`。
3. 分别在 English 和简体中文下验证 View 菜单：
   - `Outline` / `大纲` 可见且可用
   - 不显示 `Show Tab Bar` 和 `Show All Tabs`
4. 选择 Outline：
   - 右侧面板打开
   - 菜单项显示勾选
   - 面板列出示例文档标题
5. 再次选择或点击面板关闭按钮：
   - 面板关闭
   - 菜单项取消勾选
6. 打开 MarkHola 自己的 `Tab` / `标签页` 菜单，确认既有文档 Tab 命令存在。
7. 确认 File / 文件菜单没有 `Toggle Mode` / `切换模式`，Edit / 编辑菜单仍保留该命令。

### 状态四：Tab 原生式文字行为

1. 同时打开至少两个 Markdown 文档。
2. 在 Tab 文件名上从左向右和从右向左拖动鼠标。
3. 通过截图和页面选区检查确认 Tab 标题不产生文本选中高亮。
4. 确认：
   - 单击仍切换当前文档
   - 关闭按钮仍关闭目标 Tab
   - 键盘焦点样式和 Enter/Space 激活仍有效
   - Tab 溢出时前后导航仍有效
   - 文档正文文字仍可正常选中

### 状态五：双语 Help

1. English 下选择 `Help > Documentation`：
   - 打开 English Help
   - 显示 `v0.7.9`
   - View 菜单说明包含 Language、Size 和 Outline
   - 不列出 GitHub 主题、`Show Tab Bar` 或 `Show All Tabs`
2. 简体中文下选择 `帮助 > 文档`：
   - 打开简体中文 Help
   - 显示 `v0.7.9`
   - 功能和菜单说明与 English Help 等价
3. 确认切换界面语言不会修改用户 Markdown 正文。

## 布局边界

English 和简体中文的字符串长度不同。真实截图需检查：

- 一级菜单和子菜单标题没有截断或空白项。
- 查找面板、About、空工作区和 Outline 没有重叠或溢出。
- Tab 标题省略和关闭按钮布局与 v0.7.8 一致。

只在 Default 主题验证两种语言；本版本不改变 Dark 和 Light 的布局或配色，不重复主题
矩阵回归。

## 通过标准

- 自动化测试通过。
- `dist/MarkHola.app` 来自最新代码。
- 默认语言为 English，两种语言可立即切换并跨重启持久化。
- MarkHola 自有菜单、WebView、状态和确认提示的可见文案与当前语言一致。
- Tab 标题不能产生文本选区，既有 Tab 交互和正文选择不受影响。
- 空工作区和已打开文档中 Outline 均有对应语言的可见标题和正确状态。
- 两种状态下都看不到 `Show Tab Bar` 和 `Show All Tabs`。
- MarkHola 自己的 Tab 菜单和 WebView 文档 Tab 行为保持正常。
- 两种 Help 文件的版本和菜单说明与 `v0.7.9` 一致。
