# v0.7.9 本地 Markdown 链接复用测试

## 测试目标

验证点击本地 Markdown 链接时：

- 目标文件已打开会直接切换到对应 tab，不创建重复 tab
- 目标文件未打开会创建新 tab，并切换到该 tab
- 页内锚点和 `http/https` 外链行为保持不变

## 自动化测试

1. 运行：

   ```bash
   cargo test
   ```

2. 验证工作区仍满足：
   - 同一路径再次打开只激活现有文档
   - 不会生成重复文档条目
3. 验证 WebView 脚本源码包含：
   - `a[href]` 点击分支
   - `href.startsWith("#")` 锚点分支
   - `href.startsWith("http://") || href.startsWith("https://")` 外链分支
   - 本地 Markdown 链接识别分支
   - 对本地 Markdown 链接的 `preventDefault()`
   - 发送新的 IPC 打开消息
4. 验证 `ipc.rs` 能识别新的 IPC kind，并继续落到现有打开链路。
5. 验证 `bootstrap.rs` 仍保留本地 Markdown `file://` 导航兜底拦截。

## 构建验证

运行：

```bash
./scripts/build_app.sh
```

确认 `dist/MarkHola.app` 来自最新源码。

## 真实界面验证

### 状态一：目标文件已打开

1. 启动最新 `dist/MarkHola.app`。
2. 先打开：
   - `examples/workspace-visual.md`
   - `examples/languages.md`
3. 回到 `workspace-visual.md` tab。
4. 点击其中指向 `languages.md` 的本地 Markdown 链接。
5. 确认：
   - 当前活动 tab 切换为 `languages.md`
   - tab 总数不增加
   - 没有出现第二个同名 `languages.md` tab

### 状态二：目标文件未打开

1. 在同一工作区里关闭 `mermaid.md`，确保它未打开。
2. 回到 `workspace-visual.md`。
3. 点击其中指向 `mermaid.md` 的本地 Markdown 链接。
4. 确认：
   - 新增一个 `mermaid.md` tab
   - 新 tab 自动成为活动 tab
   - 文档内容成功渲染

### 状态三：既有链接行为不回退

1. 在 `workspace-visual.md` 内点击页内锚点。
2. 确认：
   - 不新开 tab
   - 仍滚动到当前文档目标段落
3. 点击一个 `http` 或 `https` 外链。
4. 确认：
   - 仍走系统外部打开流程
   - 不在当前工作区创建新 Markdown tab

## 示例方向

复用 `examples/workspace-visual.md`，新增一组本地 Markdown 链接：

- 一个指向 `languages.md`
- 一个指向 `mermaid.md`
- 一个页内锚点链接

这样一份文档即可覆盖“已打开复用”“未打开新开”“页内锚点保持不变”三类场景。

## 通过标准

- 自动化测试通过。
- 最新 `dist/MarkHola.app` 构建成功。
- 已打开目标文件时，只切换活动 tab，不产生重复 tab。
- 未打开目标文件时，新开 tab 并自动切换过去。
- 页内锚点和外链行为保持不变。
