# v0.7.8 字体大小技术设计

## 范围

`v0.7.8` 在现有原生 `View` 菜单中增加文档字体大小控制。

确认后的菜单结构：

- `View > Size > Zoom In`
- `View > Size > Zoom Out`
- `View > Size > Reset`

本版本不增加字体选择功能，也不缩放原生底栏、Tab、预览标题栏、查找控件、对话框或其他应用外壳元素。

## 用户可见行为

### 默认大小

默认大小为 `100%`。

在 `100%` 状态下，只读 Markdown 和可写编辑器继续使用 `v0.7.7` 的字体大小，因此升级到 `v0.7.8` 后，默认视觉效果不会发生变化。

### 放大

每次执行 `Zoom In`，文档字体大小增加 10 个百分点。

最大值为 `200%`。达到最大值后继续执行放大，不再增加。

### 缩小

每次执行 `Zoom Out`，文档字体大小减少 10 个百分点。

最小值为 `50%`。达到最小值后继续执行缩小，不再减少。

### 重置

执行 `Reset` 后，文档字体大小恢复为 `100%`。

### 字号作用范围

字号设置统一作用于：

- 只读 Markdown 正文和标题
- 只读模式的行内代码及代码块文字
- 可写编辑器文字
- 可写编辑器行号

所有已打开文档共用同一个字号设置，并且在以下操作后保持不变：

- 在只读和可写模式之间切换
- 切换文档
- 切换应用主题
- 进入或退出全屏
- 同一次运行期间恢复应用 WebView 外壳
- 退出并重新打开应用

首次启动，或不存在有效的已保存配置时，应用使用 `100%`。

用户放大、缩小或重置字号后，应用立即保存结果。下次启动时，在展示文档内容前恢复上次保存的字号。

## 实现方案

### 原生菜单

在现有 `View` 菜单的 `Theme` 后增加 `Size` 子菜单。

三个子菜单项分别发送独立事件：

- 放大文档字体
- 缩小文档字体
- 重置文档字体

本版本不增加新的键盘快捷键。

### 原生菜单

字号只通过 `View > Size` 子菜单调整。原生底部状态栏保持只读，不展示字号，也不提供字号操作。

### 运行时状态

在应用运行时保存当前文档字号百分比。

运行时规则：

- 初始值来自已保存的用户偏好
- 未保存有效值时使用 `100`
- 每次增加或减少 `10`
- 将结果限制在 `50..=200`
- 重置时恢复为 `100`

字号保存在 Rust 运行时中，确保应用外壳恢复或重新创建时可以重新应用当前值。

### 用户偏好持久化

扩展现有的 macOS 用户偏好机制。该机制已经用于保存主题选择，不再新建第二套配置系统。

使用稳定的 `NSUserDefaults` 配置项：

- Key：`documentSizePercent`
- 保存值：整数百分比
- 有效值：`50..=200` 范围内以 `10` 为步进的整数
- 无效值回退：`100`

应用启动时，在创建初始 WebView 外壳前读取该值。

执行以下操作后立即保存：

- `Zoom In`
- `Zoom Out`
- `Reset`

配置不存在、无法读取为整数、超出支持范围或不符合 10% 步进时，忽略该配置并使用 `100%`。

### WebView 应用方式

应用外壳暴露一个接收百分比的函数，在不重新加载当前文档的情况下更新内容字体。

该函数调整预览和编辑器排版，同时保持周围应用外壳尺寸不变。标题之间的相对比例、编辑器文字和行号的行高对齐必须保持正确。

启动时将恢复后的字号传入初始应用外壳，避免文档先短暂显示为 `100%`，再跳变为已保存字号。

### 主题兼容

三个主题在 `100%` 时继续使用各自现有字体大小：

- `default`
- `dark`
- `light`

切换主题后必须保留当前百分比，并以新主题的正常字体大小为基准计算显示字号。

### 状态反馈

执行字号操作后，WebView 状态通知显示当前百分比，例如：

- `Document size increased to 110%.`
- `Document size decreased to 90%.`
- `Document size reset to 100%.`

## 验证策略

### 自动化验证

- 验证无保存配置时运行时字号为 `100%`
- 验证放大和缩小按 10 个百分点变化
- 验证结果限制在 `50%..=200%`
- 验证重置恢复为 `100%`
- 验证缺失或无效配置回退为 `100%`
- 验证有效配置可以恢复
- 验证放大、缩小和重置都会保存结果
- 验证应用外壳暴露字号应用函数
- 验证 `View` 菜单包含 `Size` 及三个子菜单项

### 手动验证

- 验证 `100%` 与 `v0.7.7` 字体视觉一致
- 验证只读模式的三个菜单操作
- 验证可写模式的三个菜单操作
- 验证编辑器文字和行号保持对齐
- 验证字号在模式、Tab、主题和全屏切换后保持不变
- 验证应用外壳和原生底栏不随字号缩放
- 验证首次启动使用 `100%`
- 验证退出并重新启动后恢复上次字号
- 验证重置到 `100%` 后重新启动仍保持 `100%`
