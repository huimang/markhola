# v0.7.9 尖括号链接简写测试

## 测试目标

验证 `<xx>` 会按 `[xx](xx)` 渲染为链接，同时不破坏代码区域和 HTML 片段。

## 自动化测试

1. 运行：

   ```bash
   cargo test
   ```

2. 验证：
   - `<README.md>` 渲染成 `<a href="README.md">README.md</a>`
   - `<docs/intro.md>` 渲染成对应链接
   - `<https://example.com>` 仍渲染成可点击链接
   - 行内代码 `` `<README.md>` `` 不变
   - fenced code block 中的 `<README.md>` 不变
   - 原生 HTML 标签如 `<b>`、`<div>` 不被转成链接

## 构建验证

运行：

```bash
./scripts/build_app.sh
```

确认 `dist/MarkHola.app` 已更新。

## 真实界面验证

使用 `examples/angle-bracket-links.md`，确认：

1. 只读模式下：
   - 尖括号简写显示为可点击链接
   - 本地路径和 URL 都可点击
2. 可写模式下：
   - 仍显示原始源码 `<README.md>`
   - 保存后源码不被改写成 `[README.md](README.md)`
3. 代码区域中：
   - 行内代码与 fenced code block 内的尖括号内容不被链接化

## 通过标准

- 自动化测试通过
- 真实界面中 `<xx>` 可按链接工作
- writable mode 保留原始 Markdown 源码
- 代码和 HTML 片段不被误处理
