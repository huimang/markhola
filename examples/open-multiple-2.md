# Multiple File Opening - Document 2

This is the second document for demonstrating multi-file opening.

When you select both `open-multiple-1.md` and `open-multiple-2.md` in the file dialog, both should open in separate tabs.

## Tab Behavior

- Each document gets its own tab
- Switch between tabs using `Ctrl+Tab` or by clicking
- Close individual tabs with `Ctrl+W`
