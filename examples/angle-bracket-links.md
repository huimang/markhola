# Angle Bracket Links

Use this document to verify the `v0.7.9` angle-bracket shorthand links.

## Rendered links

- <README.md>
- <docs/visual-design-guidelines.md>
- <https://example.com>

## Inline code should stay literal

`<README.md>`

## Fenced code should stay literal

```text
<README.md>
<https://example.com>
```

## HTML-like tags should not become links

<b>bold-like tag</b>
